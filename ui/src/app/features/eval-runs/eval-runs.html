Evaluation

Is the assistant good enough? Live quality watches real chats; Test-set checks measure search against questions with known answers before and after a settings change.

Each check searches with test questions whose answers are known (search only: no AI answers, free, about a second) and compares Recall and MRR with the release gates. Run quality check uses the built-in test set; Use my test set takes your own questions for your documents.

help_outline Test set format

A .jsonl file with one question per line. Answerable questions name the document and an exact quote that contains the answer (it must appear exactly once). Include some questions the documents cannot answer ("answerable": false). Document paths are shown on the Documents page.
